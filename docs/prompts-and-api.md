# Pre-written Content and Prompts

The site makes no calls to any generation API. Everything that used to be generated by Claude at request time is written ahead of time and loaded from JSON files in `src/data/`.

## Data Files (`src/data/`)

| File                     | Shape                                                          | Used by                                                       |
| ------------------------ | -------------------------------------------------------------- | ------------------------------------------------------------- |
| `error-poems.json`       | `string[]`                                                     | `PageNotFound`, `research/poetic-404/Prototype.tsx`           |
| `research-taglines.json` | `string[]`                                                     | `research/research-lab-as-container/Prototype.tsx`            |
| `pangrams.json`          | `{ pangram, words: [{ word, partOfSpeech, definition, analysis }] }[]` | `research/collections-of-meaningless-words/Prototype.tsx` |
| `diagrams.json`          | `{ name, vertical, horizontal, items }[]`                      | `app/diagram/PageDiagram.tsx` (see `src/app/diagram/CLAUDE.md`) |

Import them directly; `resolveJsonModule` is enabled:

```typescript
import poems from "@/data/error-poems.json";
```

## "Generate" Without an API

`ButtonGenerate` takes a `pool` of pre-written strings. "generate" reveals a random item the reader hasn't seen yet after a short spin (300ms); once the pool is exhausted it draws from the whole pool again. See [Component Architecture](./components.md#buttongenerate).

```typescript
const { currentText, controls } = ButtonGenerate({
  pool: poems,
  initialCount: 2,
});
```

## Adding or Editing Content

1. Edit the relevant JSON file in `src/data/` (keep the existing shape).
2. For a new pool, add a JSON file and import it where needed.
3. Run `npx tsc --noEmit` to catch shape mismatches.

## Prompts (`src/prompts/`)

Only `discuss-research.ts` remains. `Footer` uses `DISCUSS_RESEARCH_PROMPT(url)` to build a "discuss" link that opens Claude.ai with the prompt prefilled. It is a link, not an API call.
